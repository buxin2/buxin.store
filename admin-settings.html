Important publishing note

This starter saves product data in this browser's LocalStorage. It is ideal for previewing and testing the complete flow, but changes will not appear on other visitors' devices. For a live shared catalogue, connect a secure publishing workflow (for example, GitHub Actions with a protected token) before deployment. Do not expose publishing tokens in frontend JavaScript.
