Store settings

Set the WhatsApp number that receives customer orders. Saved settings stay until you change them.

Customers can message from any country. Enter the full international number with country code, digits only (no +, spaces, or dashes). Example India: 91XXXXXXXXXX. Saving here only updates this computer until you Lock site data house and PUSH — phones and other visitors use the pushed number.

Site data house

This is the memory for WhatsApp, shipping, pricing, and Gambia stock. Lock it into the website so a new PUSH does not wipe your settings.

After you save anything in admin, click Lock, replace js/store-data.js with the downloaded file, then PUSH. Everyone will keep those settings.

Image hosting (optional)

Configure Cloudinary unsigned uploads to upload product photos from here.

Create an unsigned upload preset in Cloudinary. These values are public configuration; never put your Cloudinary API secret here.

How settings stay safe

Admin changes are remembered in this browser right away. To keep WhatsApp, shipping, pricing, and Gambia marks after PUSH for every visitor, use Site data house above and lock them into js/store-data.js before you push.
